# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.9.1] - 2026-03-15

### Added

- Obsidian theme support
- Bidirectional OpenCode Desktop theme support

## [0.7.0] - 2026-03-13

### Changed

- Improved UX across preview, apply, and color picker

## [0.5.1] - 2026-03-11

### Fixed

- Removed dot prefix from theme store path for macOS visibility

## [0.5.0] - 2026-03-10

### Fixed

- Improved central theme store UX and fixed Superset import

## [0.4.1] - 2026-03-10

### Added

- TUI-based live theme preview with ratatui

### Fixed

- Improved update command UX with confirmation and brew sync

## [0.4.0] - 2026-03-10

### Added

- TUI-based live theme preview with ratatui

### Fixed

- Resolved Ghostty theme path to XDG directory and stripped alpha from colors
- Resolved CI failures (fmt + typos config for ratatui)

## [0.3.1] - 2026-03-09

### Fixed

- Resolved Ghostty theme path to XDG directory and stripped alpha from colors

## [0.3.0] - 2026-03-09

### Added

- Update notifier and self-update command
- Ghostty target support

## [0.2.0] - 2026-03-09

### Added

- Ghostty target support and improved code quality

## [0.1.0] - 2026-03-08

### Added

- Initial release
- VS Code and Cursor theme scanning
- Superset and Warp target support
- Interactive theme selection
- Central theme store (`~/.config/chromaport/themes/`)
- Homebrew and Cargo installation
